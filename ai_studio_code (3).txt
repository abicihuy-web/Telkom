# 📡 Dashboard Executive Monitoring & Risk Management — PT Telkom Indonesia Tbk (FY 2025)

Dashboard analitik eksekutif berbasis **Streamlit** dan **Plotly** untuk memantau kinerja keuangan konsolidasian, mengelola risiko kredit/piutang (*bad debt*), melacak *churn* pelanggan & ARPU pasca-merger kompetitor, serta mengevaluasi kesehatan portofolio investasi dan entitas anak PT Telkom Indonesia Tbk Tahun Fiskal 2025.

## ✨ Fitur Utama

1. **📊 Financial & Operational Overview**
   - KPI Konsolidasian: Pendapatan (Rp146.742 Miliar), Laba Bersih (Rp17.814 Miliar), EBITDA Margin (49,2%).
   - *Waterfall Chart* pergeseran pendapatan dari *Legacy Voice/SMS* (-29,7% YoY) ke layanan *Data & Digital*.
2. **⚠️ Credit Risk & Bad Debt Analytics**
   - Pemantauan cadangan piutang (Rp6.955 Miliar) dan lonjakan beban provisi (+62,1% YoY).
   - *Aging Schedule* piutang (`0-30`, `31-60`, `61-90`, `>90 hari`) segmen Enterprise vs Government.
   - **Interactive Credit Recovery Simulator** untuk memproyeksikan *cash flow recovery* dan potensi *reversal* provisi.
3. **📉 Subscriber Churn & ARPU Tracker**
   - Tren kuartalan (Q1–Q4 2025) pelanggan Seluler (156,1 Juta, *net churn* -3,3 Juta) & IndiHome.
   - Komparasi ARPU Telkomsel vs kompetitor pasca-merger **XLSmart** (*Bar Chart* & *Heatmap*).
4. **🏢 Subsidiary & Investment Health Check**
   - Pemantauan *unrealized loss* investasi GoTo/MDI (-Rp242 Miliar) dan rugi bersih Telkomsat (-Rp249,5 Miliar).
   - Alokasi portofolio investasi digital & *Scorecard* kesehatan keuangan entitas anak (Telkomsat, InfraNexia, Mitratel, dll.).

## 🚀 Menjalankan Secara Lokal

```bash
git clone https://github.com/<username-anda>/telkom-fy2025-risk-dashboard.git
cd telkom-fy2025-risk-dashboard
pip install -r requirements.txt
streamlit run app.py
```

## ☁️ Deploy ke Streamlit Community Cloud

1. Push seluruh file ke repositori GitHub Anda.
2. Buka [share.streamlit.io](https://share.streamlit.io/) dan hubungkan repositori GitHub.
3. Pilih `app.py` sebagai *Main file path*, lalu klik **Deploy**.
